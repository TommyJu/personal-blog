# Welcome to my blog's source code

I wanted to create my own blog so that I could share my ideas with others. 
I personally love reading and writing, I feel as though it's the ultimate medium for exchanging ideas.
I'm interested in topics such as programming, cycling, and wisdom gained from the trials and tribulations of everyday life.

## How this blog was built
This blog is a [static web page](https://crystallize.com/blog/what-is-static-site) built
with the [Hugo framework](https://gohugo.io/) and the [PaperMod Hugo theme](https://themes.gohugo.io/themes/hugo-papermod/).  

I opted for a static site because it's really fast and responsive. It's an excellent choice for websites with minimal
functionality. They're also quite easy to host because you aren't running an entire server. This is good if you
want to avoid cold-starts from free-tier hosting plans.

Hugo also uses [Markdown](https://markdown.org/) by default for content. Markdown is great because
you can format text, add images, and create links with simple plain text.
